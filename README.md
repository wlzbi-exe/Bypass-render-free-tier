<p align="center">
  <b>A lightweight Telegram bot for managing and periodically sending HTTP requests to stored URLs.</b><br>
  Built with asynchronous networking for minimal resource usage.
</p>

---

## ✨ Features

- ➕ Add URLs
- ➖ Remove URLs
- 📋 View stored URLs
- 🗑 Clear all URLs
- ⚡ Async HTTP requests
- 🎲 Random User-Agent rotation
- 💾 JSON database
- 🔄 Automatic background scheduler
- 🪶 Lightweight & optimized
- 🤖 Interactive Telegram interface

## 📦 Requirements

- Python 3.10+
- python-telegram-bot
- aiohttp

Install dependencies:

```bash
pip install -r requirements.txt
```

or

```bash
pip install python-telegram-bot aiohttp
```

---

## ⚙️ Configuration

```python
TOKEN = "YOUR_BOT_TOKEN"
PING_INTERVAL = 10
DATA_FILE = "urls.json"
```

---

## ▶️ Run

```bash
python bot.py
```
